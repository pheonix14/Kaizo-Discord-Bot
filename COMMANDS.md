# Kaizo Discord Bot - Commands Guide

This document lists features and commands available in Kaizo Discord Bot.

## Command Permissions
Every command can be restricted in the Admin Panel to:
- [ ] Premium Users
- [ ] People who joined the Discord
- [ ] Selected Special Users / Testers

## Categories

### 1. Help Commands
- `/help`: Displays category-wise help.
- `/help <command>`: Shows specific command usage.

### 2. Moderation
- `/mute`, `/warn`, `/ban`, `/kick`: Standard moderation actions.
- Anti-spam, Anti-raid, Link protection run automatically.

### 3. Economy & Social
- `/profile`: View your social profile.
- `/wallet`: Check your coin balance.
- `/like <user>`: Like a user's profile.
- `/search <username>`: Search for users.

### 4. Media
- `/play <link>`: Play audio from a link in your voice channel.
- `/video <link> <quality>`: Download/Stream a video with selected quality.

### 5. Verification & Support
- `/verify`: Complete captcha to gain server access.
- `/ticket create`: Open a custom support ticket.
- `/appeal`: Submit a ban appeal (sent to admins).

### 6. Utility & Developer
- `/serverinfo`: Shows server information.
- `/dev id`: Shows Channel ID and User ID.
- `/uptime`: Displays bot uptime.
- `/invite`: Gives an invite link to the user.
