K4 Defence / Automod System

The K4 Defence module automatically protects your server from active raids, spam attacks, excessive mentions, and duplicated content. It enforces limits dynamically and sends detailed reports to security logs.

Enable Protection
Toggle the central spam/nuke defence filter for the server.
k!k4defence enable
Check System Status
Check configuration details and active security parameters.
k!k4defence status
Configure Logging
Set the target security log channel for anti-nuke audit logs.
k!automod modlog_set [channel]
Economy & Store System

Users can earn virtual coins, deposit funds into their bank accounts, work, and purchase custom server rewards (like roles, badges, and collectable items) directly from the dashboard or through prefixes.

Check Balance
View the current amount of coins in your wallet and bank.
k!eco balance
Work Command
Work to earn standard currency. Subject to server cooldown.
k!eco work
Buy from Shop
Purchase a reward item or role using your wallet coins.
k!eco_shop buy [item_name]
Music & Downloader Console

High-fidelity voice channel streaming system. Supports YouTube URLs, search queries, active audio queue management, sound loop adjustments, and direct audio file downloads.

Play Audio
Join voice channel and start streaming audio from keyword or URL.
k!music play [query]
Download MP3
Directly fetch and download an MP3 audio track from YouTube.
k!music download [query]
Audio Filters
Apply customized sound DSP effects (like bassboost or nightcore).
k!music filter [filter_name]
Core Utilities & Tools

Basic utility, info gathering, polling, translation, and user helper commands built to make server administration easier.

Server Info
Display detailed analytics, role metrics, and creation date of the server.
k!info server
AFK Status
Set an AFK note. The bot will automatically notify anyone who pings you.
k!tools afk [reason]
Generate Embed
Launch the interactive builder to send customized embed messages.
k!embed
