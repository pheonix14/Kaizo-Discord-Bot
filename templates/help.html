K4 Defence / Automod System

The K4 Defence module automatically protects your server from active raids, spam attacks, excessive mentions, and duplicated content. It enforces limits dynamically and sends detailed reports to security logs.

Enable Protection
Toggle the central spam/nuke defence filter for the server.
k!k4defence enable
Check System Status
Check configuration details and active security parameters.
k!k4defence status
Configure Logging
Set the target security log channel for anti-nuke audit logs.
k!automod modlog_set [channel]
Economy & Store System

Users can earn virtual coins, deposit funds into their bank accounts, work, and purchase custom server rewards (like roles, badges, and collectable items) directly from the dashboard or through prefixes.

Check Balance
View the current amount of coins in your wallet and bank.
k!eco balance
Work Command
Work to earn standard currency. Subject to server cooldown.
k!eco work
Buy from Shop
Purchase a reward item or role using your wallet coins.
k!eco_shop buy [item_name]
Shorthand Balance
Quickly check your balance.
k!bal
Shorthand Work
Quickly work for coins.
k!work
Shop List
View the server shop items available for purchase.
k!shop
Buy Item
Purchase an item from the shop.
k!buy [item_name]
Sell Item
Sell an item from your inventory back to the shop.
k!sell [item_name]
View Inventory
Check your collected or purchased items.
k!inv
Use Item
Consume or use an item from your inventory.
k!use [item_name]
Music & Downloader Console

High-fidelity voice channel streaming system. Supports YouTube URLs, search queries, active audio queue management, sound loop adjustments, and direct audio file downloads.

Play Audio
Join voice channel and start streaming audio from keyword or URL.
k!music play [query]
Search & Play
Search YouTube for top 5 results and play via interactive selection buttons.
k!music search [query]
Download MP3
Directly search, fetch, and download an MP3 audio track from YouTube.
k!music download [query]
Audio Quality
Set default session download quality (64, 96, 128, 192, 256, 320 kbps).
k!music quality [kbps]
Skip Track
Skip the currently playing audio track.
k!music skip
Stop Playback
Stop streaming and clear the entire playback queue.
k!music stop
Pause / Resume
Pause or resume current audio playback.
k!music pause / resume
Volume Control
Adjust output volume (1% - 200%).
k!music volume [level]
Loop Mode
Toggle loop mode for current song, entire queue, or disable it.
k!music loop [off/song/queue]
Active Queue
Display the list of scheduled audio tracks in the queue.
k!music queue
Audio Filters
Apply customized sound DSP effects (8d, bassboost, nightcore, vaporwave).
Filter Commands:
k!music 8d [true/false] — Toggle 8D audio drift
k!music bassboost [level] — Set bass amplification (1-30)
k!music nightcore [true/false] — Toggle Nightcore speedup
k!music vaporwave [true/false] — Toggle Vaporwave slowdown
k!music filter_off — Disable all DSP effects
k!music [filter] [options]
Save & Load Playlists
Manage custom playlists in the database.
Playlist Subcommands:
k!music playlist_save [name] — Save current queue
k!music playlist_list — List all your saved playlists
k!music playlist_load [name] — Load a playlist into active queue
k!music playlist_[action] [name]
Core Utilities & Tools

Basic utility, info gathering, polling, translation, and user helper commands built to make server administration easier.

Server Info
Display detailed analytics, role metrics, and creation date of the server.
k!info server
AFK Status
Set an AFK note. The bot will automatically notify anyone who pings you.
k!tools afk [reason]
Generate Embed
Launch the interactive builder to send customized embed messages.
k!embed
