# KAIZER X - The Ultimate Discord Bot

Welcome to **PROJECT KAIZER X**. This is a powerful, multi-purpose Discord bot designed for ultimate control, spam protection, and social interaction.

**Disclaimer:** This is a completely original project inspired by modern social networks and robust moderation tools. 

## Features
- **Admin & User Dashboard**: A 3D Parallax web UI for full control over bot settings.
- **Ultimate Moderation**: Anti-spam, anti-raid, link protection, auto-mute, auto-warn, auto-ban.
- **Social & Economy**: Level up system, coins, Instagram-style user profiles (NO EMOJIS), wallet, and market.
- **Media Player**: Play music and videos from links with full quality control.
- **Server Utility**: Welcome/Goodbye messages, announcements, channel creation, themes/skins.
- **Custom Verification & Support**: Custom Captcha/Role verification, Ticket creation system, and Ban appeals.

## File Structure
- `bot.py`: Main entry point for the Discord Bot.
- `config.py`: Configuration and environment loading.
- `cogs/`: Modular command categories.
- `database/`: SQLite/SQLAlchemy models and setup.
- `dashboard/`: Web interface backend and frontend.
